# Context Workspace

A local VS Code operator for evidence-grounded context compilers.

Open the Context Workspace icon, create or open a compiler, then use outcome-oriented
actions such as **Add Evidence**, **Prepare Brief**, and **Review Exceptions**. The
extension stores no credentials, emits no telemetry, and leaves compilation and
validation inside the versioned compiler repository.

See the repository's `docs/VSCODE-EXTENSION.md` for installation and enterprise rollout.
